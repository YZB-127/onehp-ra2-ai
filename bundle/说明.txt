一滴血的红警（由 AI 制作）
================================

把所有单位、建筑、树木、桥梁的血量压到 1 —— 碰一下就死，一发流弹能连锁拆掉半个基地。
支持两个版本：原版红警2（rules.ini）和 尤里的复仇（rulesmd.ini）。

【怎么用】
1. 需要 Python 3（安装时勾选 Add Python to PATH）
2. 原版：双击「一键应用.bat」
   尤里：双击「一键应用(尤里).bat」
   然后把游戏目录拖进去后回车（也可以直接把游戏文件夹拖到 bat 图标上）
3. 完全退出游戏，重新打开
4. 新开一局 / 从"新战役"进关卡 —— 不要读旧存档！
   红警的存档自带当时的场景数据（含各类型血量），读旧档会继续用旧数值。

【撤销】
原版：双击「撤销还原.bat」
尤里：双击「撤销还原(尤里).bat」
会从游戏目录下的 _onehp_backup / _onehpmd_backup 还原。

【只看状态、不改东西】
    python apply_onehp_mod.py "游戏目录" --check
    python apply_onehp_mod.py "游戏目录" --yr --check

【改了什么（概要）】
- 所有血量 -> 1（原版 406 处 + 尤里 555 处 Strength，还有树和桥）
- RepairStep / IRepairStep -> 1  ← 关键！1/8 会被截断成 0，直接用原版值必崩
- 7 个"0 血类型"补成 1（原版 DeathDummy 等；尤里再多 8 个）
- 任务包/地图里的"地图自带血量覆盖"全部压成 1（等长替换，文件大小不变）
  只有两个例外保留任务原值：气垫船 [SAPC] 800、自由女神像 [CANEWY04] 10000
  （这俩是任务脚本硬依赖，压到 1 会直接卡关）
- 降负载：碎片/烟尘变少（1 血时爆炸太多，这层很有必要）；连锁伤害一点没改
- game.exe / gamemd.exe 保持原版不打补丁
  （如果之前装过 5 血版、exe 上还留着那个维修补丁，脚本会自动还原 —— 1 血配那个补丁会被多收维修费）

【注意】
- 尤里那边是"往游戏目录放一份散装 rulesmd.ini"盖住打包里那份，打包文件一个字节没动。
- 仅供单机娱乐，别拿去联机。
- 本包不包含任何游戏本体文件。
