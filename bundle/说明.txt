一滴血的红警（由 AI 制作）
================================

单位血量压到 1、建筑血量压到 2 —— 碰一下就死，一发流弹能连锁拆掉半个基地。
支持两个版本：原版红警2（rules.ini）和 尤里的复仇（rulesmd.ini）。

【怎么用】
1. 需要 Python 3（安装时勾选 Add Python to PATH）
2. 原版：双击「一键应用.bat」
   尤里：双击「一键应用(尤里).bat」
   然后把游戏目录拖进去后回车（也可以直接把游戏文件夹拖到 bat 图标上）
3. 完全退出游戏，重新打开
4. 新开一局 / 从"新战役"进关卡 —— 不要读旧存档！
   红警的存档自带当时的场景数据（含各类型血量），读旧档会继续用旧数值。

【撤销】
原版：双击「撤销还原.bat」
尤里：双击「撤销还原(尤里).bat」
会从游戏目录下的 _onehp_backup / _onehpmd_backup 还原。

【只看状态、不改东西】
    python apply_onehp_mod.py "游戏目录" --check
    python apply_onehp_mod.py "游戏目录" --yr --check

【改了什么（概要）】
- 单位（步兵/载具/飞机）   血量 -> 1
- 建筑（含建造厂/防御/超武）血量 -> 2
  建筑为什么不是 1：最大血量=1 会踩引擎边界，把地图的海岸线/水面渲染成一整块青色。
  2 血实战和 1 血没区别（步枪打建筑 15 点、炮弹几十上百，都是一发）。
- RepairStep / IRepairStep -> 1   ← 关键！2/8 会被截断成 0，直接用原版值维修时必崩
- 例外（保留原版）：工程师 75（占领/拆弹要用）、围墙300 / 沙袋100 / 栅栏100、藤树、旗杆
- 任务包/地图里的"地图自带血量覆盖"压成 2（等长替换，文件大小不变）
  · 原本 > 1500 的任务目标保留原值：要占领的建造厂 30000、核电站 32000、导弹井 100000、纽约大楼 50000…
  · 脚本硬依赖的保留：气垫船 [SAPC] 800、自由女神像 [CANEWY04] 10000
  · 两版盟军最后一关的建造厂单独给 1500（红警2 ALL12 / 尤里 ALL07md，基地来得晚又挨打）
- game.exe / gamemd.exe 保持原版不打补丁
  （如果之前装过 5 血版、exe 上还留着那个维修补丁，脚本会自动还原）

【注意】
- 尤里那边是"往游戏目录放一份散装 rulesmd.ini"盖住打包里那份，打包文件一个字节没动。
- 仅供单机娱乐，别拿去联机。
- 本包不包含任何游戏本体文件。
