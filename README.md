# 一滴血的红警（由 AI 制作）

> 把所有**单位**的血量压到 **1**、所有**建筑**压到 **2** —— 任何一次攻击都是秒杀，一发流弹能引发整片基地的连锁爆炸。
>
> **两个版本都支持**：原版红警2（`rules.ini`）+ 尤里的复仇（`rulesmd.ini`）。
>
> 本仓库**不包含任何游戏本体文件**，只提供规则文件、一键脚本与技术文档。请自备正版游戏。
>
> 姊妹玩法：[tanky-ra2-ai](https://github.com/YZB-127/tanky-ra2-ai)（全员 1500 血 · 船厂硬度）。

---

## 这个玩法是什么

| 项目 | 原版 | 一滴血 |
|---|---|---|
| 步兵 / 载具 / 飞机 | 75 ~ 1500 | **1** |
| 建筑（含建造厂、防御、超武） | 400 ~ 1500 | **2** |
| 维修参数 `RepairStep` / `IRepairStep` | 8 / 20 | **1 / 1**（必须，见下） |
| 结果 | 正常交火 | **碰一下就没，油桶/核电站/炼油厂连锁能把半个基地送走** |

### 建筑为什么是 2 而不是 1

`最大血量 = 1` 会踩到引擎的边界：RA2/YR 有一大批建筑逻辑按**血量比例**算（受损帧、受击状态、灭火阈值…），
分母为 1 时全部退化，实测表现为**地图的海岸线/水面被渲染成一整块青色**（单位和建筑本身正常）。
改成 2 就完全正常，而实战手感和 1 血**没有任何区别** —— 步枪打建筑 15 点、任何炮弹几十上百，都是一发。

> 详细排查过程见 [改动清单.md](改动清单.md)。

### 必须保留的例外

| 类型 | 值 | 原因 |
|---|---|---|
| 工程师 `[ENGINEER]` / `[SENGINEER]` | **75**（原版） | 任务工具（占领 / 拆弹），1 血走两步就没了，会让很多关卡直接无解 |
| 围墙 `[GAWALL]` `[NAWALL]` `[CAKRMW]` | 300 | 地形层物件，跟"建筑血量"不是一回事 |
| 沙袋 / 栅栏 `[GASAND]` `[CAFNCB]` `[CAFNCW]` `[CAFNCP]` `[GAFWLL]` | 100 ~ 300 | 同上 |
| 藤树 `[VEINTREE]`、旗杆 `[CAIRFGL]`、`[UFO]` | 原版 | 装饰 / 占位类型 |
| **两版盟军最后一关的建造厂** | **1500** | 红警2 ALL12（超时空风暴）、尤里 ALL07md：基地来得晚又挨打，2 血根本守不住 |

其余全部按上面的口径：**单位 1、建筑 2**。

### 任务图里"地图自带血量覆盖"

任务图内部可以给某个类型单独写血量（例如"这一关的苏军建造厂 30000 血"）。处理规则：

- 原本 **≤ 1500** → 压成 **2**
- 原本 **> 1500** → **保留原值**（这些都是关卡刻意做硬的目标：要占领的建造厂 30000、核电站 32000、
  导弹井 100000、纽约大楼 50000…压掉会让关卡直接没法打）
- 极少数脚本硬依赖（气垫船 `[SAPC]` 800、自由女神像 `[CANEWY04]` 10000）保留原值

全部**等长替换**：11 个任务包文件大小与原版一字节不差。

## 为什么必须把 `RepairStep` 改成 1

游戏算维修费的那段代码（`game.exe` 0x6DAEC0，建筑/单位/步兵/飞机四张虚表共用）：

~~~
维修费 = max(1, ( 造价 / ( 血量上限 / RepairStep ) ) × RepairPercent )
                          └── 整数除法，会截断 ──┘
~~~

- 原版血量 125~1500、`RepairStep=8` → 商 ≥ 15，永远安全
- **血量压到 1~2 之后：`2 / 8 = 0` → 下一步拿这个 0 当除数 → `EXCEPTION_INT_DIVIDE_BY_ZERO`**
- 所以规则里把 `RepairStep` 和 `IRepairStep` 都改成 **1** → 商 = 血量 ≥ 1，安全

### 不需要给 exe 打补丁

5 血版为了让 `血/RepairStep` 不截断成 0，给 `game.exe` 打过 6 字节补丁（`idiv` → `mov eax,5`）。
本模式**不需要**。反过来说：**如果 exe 上还留着那个补丁要撤掉**（它按"商=5"算维修费），一键脚本会自动检查并还原。

## 安装

~~~bash
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版"          # 只改原版红警2
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --yr     # 只改尤里的复仇
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --all    # 两个都改
~~~

撤销 / 查状态：

~~~bash
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --undo        # 还原原版那边
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --yr --undo   # 只还原尤里那边
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --all --undo  # 两个都还原
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --check       # 只看状态
~~~

小白包：双击 `bundle/一键应用.bat`（原版）或 `bundle/一键应用(尤里).bat`，把游戏目录拖进去回车。

> ⚠️ **改完必须完全退出游戏再重开**（规则/地图只在启动时读一次）。
> ⚠️ **应用后请新开关卡/遭遇战，不要读旧存档**：红警存档自带当时的场景数据（含各类型血量），
> 读旧档会继续用旧数值。

逐个类型的血量清单见 [血量清单.md](血量清单.md)。

## 技术细节（摘要，详见 [docs/技术细节.md](docs/技术细节.md)）

### 任务包只能"等长"改

任务包（`.mix` / `.mmx` / `.yro`）的索引用 Blowfish 加密，记着每个文件的偏移和长度，动长度就得重写加密索引。
所以一律等长替换：

- **压血量**：`Strength=1000` → `Strength=2   `（空格补齐，长度不变）
- **插覆盖段**（最后一关建造厂 1500）：MIX 里没有空位，就把图内 `0.880000` 这类小数去掉无意义尾零
  （等值改写）腾出字节，再插入覆盖段，差额用空行补齐 —— 打包文件总长度一字节不变

改完自查：文件大小、段总数、`[Basic]` `[Header]` `[Map]` `[IsoMapPack5]` `[Structures]` `[Triggers]`
出现次数与原版一一核对。

### 尤里的复仇：规则走散装文件

YR 的 `rulesmd.ini` 打包在 `expandmd01.mix` / `ra2md.mix` 里（索引加密）。不用去啃加密索引：

> `rulesmd.ini` 抬头写着：*If placed in game directory, it will override built in values.*

往游戏目录放一份散装 `rulesmd.ini` 就能盖住打包里那份，**打包文件一个字节都不用动**。

### 可复现性

从原版（仓库不提供，请自备）跑一遍脚本，产出的 13 个文件与作者机器上的安装状态**逐字节一致**；
`--undo` 能干净还原。脚本只用 Python 标准库，无第三方依赖。
