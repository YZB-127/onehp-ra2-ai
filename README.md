# 一滴血的红警（由 AI 制作）

> 把所有单位、建筑、树木、桥梁的血量全部压到 **1** —— 任何一次攻击都是秒杀，一发流弹能引发整片基地的连锁爆炸。
>
> **两个版本都支持**：原版红警2（`rules.ini`）+ 尤里的复仇（`rulesmd.ini`）。
>
> 本仓库**不包含任何游戏本体文件**，只提供规则文件、一键脚本与技术文档。请自备正版游戏。
>
> 姊妹玩法：[crispy-ra2-ai](https://github.com/YZB-127/crispy-ra2-ai)（全员 5 血 · 一枪一栋楼）、
> [tanky-ra2-ai](https://github.com/YZB-127/tanky-ra2-ai)（全员 1500 血 · 船厂硬度）。

## 这个玩法是什么

| 项目 | 原版 | 一滴血 |
|---|---|---|
| 步兵 / 载具 / 飞机 / 建筑 | 75 ~ 1500 | **1** |
| 树木 / 桥梁 | 200 / 1500 | **1** |
| 维修参数 `RepairStep` / `IRepairStep` | 8 / 20 | **1 / 1**（必须！见下） |
| 结果 | 正常交火 | **碰一下就没，油桶/核电站/油井连锁能把半个基地送走** |

比 5 血更极端：5 血至少还有"打几枪"的余地，1 血是**任何伤害都必死**，步兵互相看一眼就死人。

## 两个必须保留的任务例外

任务图里有极少数东西是**任务脚本依赖的**，压成 1 血会直接过不了关，所以保留任务原值：

| 位置 | 类型 | 保留值 | 原因 |
|---|---|---|---|
| 苏军第二关 `maps02.mix` | 气垫船 `[SAPC]` | 800 | 任务原本的强化值，压到 1 会一碰就沉，运兵任务直接废 |
| 盟军第一关 / 苏军第三关 | 自由女神像 `[CANEWY04]` | 10000 | 任务是"守住它"，压到 1 一开局就没了 |

其余**全部压成 1**（原版 117 处、尤里 85 处覆盖）。

## 为什么必须把 `RepairStep` 改成 1

游戏算维修费的那段代码（`game.exe` 0x6DAEC0，建筑/单位/步兵/飞机四张虚表共用）：

```
维修费 = max(1, ( 造价 / ( 血量上限 / RepairStep ) ) × RepairPercent )
                          └── 整数除法，会截断 ──┘
```

- 原版血量 125~1500、`RepairStep=8` → 商 ≥ 15，永远安全
- **血量压到 1 之后：`1 / 8 = 0` → 下一步拿这个 0 当除数 → `EXCEPTION_INT_DIVIDE_BY_ZERO`**
- 所以 `rules.ini` / `rulesmd.ini` 里把 `RepairStep` 和 `IRepairStep` 都改成 **1** → `1/1 = 1`，安全

### 这次不用给 exe 打补丁（和 5 血版的区别）

5 血版为了让 `血/RepairStep` 不至于截断成 0，除了改 `RepairStep=1`，还给 `game.exe` 打过一个 6 字节补丁
（`idiv [ecx+0x1334]` → `mov eax,5`，把商固定成 5）。

本模式**不需要**：`RepairStep=1` 时商恒等于血量 = 1 ≥ 1，物理上不可能除零。
反过来说，**如果你之前装过 5 血版、exe 上还留着那个补丁，必须撤掉** ——
那个补丁按"商=5"算维修费，1 血时会被多收好几倍。一键脚本会自动检查并还原。

另外还有 **7 个"类型表里有、但没有可用 Strength"的类型**（原版 `DeathDummy` + 6 个缺段落，
尤里再多 8 个），引擎按 0 血处理 → `0/1 = 0` → 同样除零。规则文件里已全部补成 `Strength=1`。

## 安装

```bash
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版"          # 只改原版红警2
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --yr     # 只改尤里的复仇
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --all    # 两个都改
```

撤销 / 查状态：

```bash
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --undo        # 还原原版那边
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --yr --undo   # 只还原尤里那边
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --all --undo  # 两个都还原
python apply_onehp_mod.py "D:\RAY2\红色警戒2 完整版" --check       # 只看状态
```

小白包：双击 `bundle/一键应用.bat`（原版）或 `bundle/一键应用(尤里).bat`，把游戏目录拖进去回车。

> ⚠️ **改完必须完全退出游戏再重开**（规则只在启动时读一次）。
> ⚠️ **应用后请新开关卡/遭遇战，不要读旧存档**：红警的存档自带当时的场景数据（含各类型血量），
> 读旧档会继续用旧数值。

## 技术细节（摘要，详见 [`docs/技术细节.md`](docs/技术细节.md)）

### 任务包只能"等长"改 —— 但这次全是变短，最安全

任务包（`.mix` / `.mmx` / `.yro`）的索引用 Blowfish 加密，记着每个文件的偏移和长度，**动长度就得重写加密索引**。
所以一律等长替换：`Strength=` 的 `S` 改 `;` 注释掉（回落规则文件），或者把数字换成 `1` 再用**空格补齐**——
`Strength=1000` → `Strength=1   `。因为这次目标值是 1 位数，**永远比原值短**，不需要像 1500 版那样去"借字节"。

改完必须自查：文件大小、段总数、`[Basic]` `[Header]` `[Map]` `[MultiMaps]` `[Digest]`
`[IsoMapPack5]` `[Structures]` `[Units]` `[Triggers]` `[Waypoints]` 出现次数必须与原版**一个不差**。

### 尤里的复仇：规则不在散装文件里

YR 的 `rulesmd.ini` 打包在 `expandmd01.mix` / `ra2md.mix` 里（索引加密）。不用去啃加密索引：

> `rulesmd.ini` 的抬头写着：*If placed in game directory, it will override built in values.*

往游戏目录放一份散装 `rulesmd.ini` 就能盖住打包里那份，**打包文件一个字节都不用动**。
（这整合版里有 3 份 YR 规则，实际生效的是 `expandmd01.mix` 那份 —— 详见 docs。）

### 降负载（1 血比 5 血更需要）

1 血时什么东西都是一碰就炸，爆炸、碎片、烟尘会比 5 血多一个量级，正好是"堆压力型崩溃"的高发场景。
所以压掉了碎片/烟尘，**但连锁伤害一个都没改**：

| 键 | 处理 |
|---|---|
| `MaxDebris` | ≤ 4 |
| `MinDebris` | ≤ 1 |
| `DamageParticleSystems` | 每类只留 1 套 |
| `[OilExplosionWH] DelayKillFrames` | 15 |

## 七、v1.1 修正（实测发现的两个问题）

### 1. 任务图里原本 > 1500 的目标不再压成 1
**症状**：盟军最后一关开局要用工程师占领苏军基地，但**占领不了、无法开局**。
**原因**：那张图里苏军建造厂 `[NACNST]` 原本是 **30000 血**（关卡刻意做硬），被本模式压成 **1 血** →
一发流弹就没了，也就没有可占领的目标了。同类还有 `[NANRCT]=32000`、`[NAMISL]=100000`、`[GAPOWR]=8500`、`[PDPLANE]=32000`。
**修法**：策略改为 —— **任务图里原本 > 1500 的覆盖一律保留原值**（和 1500 血版同一套原则），其余仍压成 1。
保留清单（原版）：`NACNST` 30000 · `NANRCT` 32000 · `NAMISL` 100000 · `PDPLANE` 32000 · `GAPOWR` 8500 ·
`CANEWY12`/`CANEWY18`/`CAPARS04` 50000 · `CAPARS01` 30000 · `CANEWY04` 10000 · `DRED`/`VLAD` 10000 ·
`INGALITE` 6000 · `NAPSYB` 2500 · `MAYAN` 2000 · `SAPC` 800 · `CABUNK01` 2000；
尤里侧同样保留 `CAPOWR*`/`GAPOWR*` 5000 系列、`SNODUSLAMP` 6000、`CALOND04`/`CATRAN03` 5000、`DNOAA` 3500、`CATIME01` 2500、`CASANF11`/`GTGCAN` 2000、`CALAB` 25000。

改动后处数：原版 `maps01` 压 42 / 留 10、`maps02` 压 47 / 留 15、`MULTI` 压 1 / 留 3、`EB2` 压 1、`Hills` 留 1；
尤里 `mapsmd03` 压 52 / 留 15、`multimd` 压 4 / 留 10、`DeepFrze` 压 1、`HighExpR` 留 1、`MonsterM` 压 1、`Transylv` 留 1。
文件大小依旧全部不变。

### 2. `TreeStrength` 回原版 200
树在 RA2 里是带**受损帧**的地形物件，血量 1 时随便一发流弹就打成"满损伤"，画面上会变成焦枯的树；
而且被摧毁后满地碎屑会加剧"画面脏"。树不参与战斗，所以直接放回原版值：
`[General] TreeStrength: 1 → 200`（`[TREE01]`~`[TREE21]` 段落本模式一个键都没动）。

> 备注：树发青的问题另有排查记录 —— 树血量已回原版仍青，说明**不是血量引起**，属渲染层（cnc-ddraw 的半透明/放大路径），
> 与规则无关。
